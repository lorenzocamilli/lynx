HTTP security toolkit

Lynx — intercept, inspect,
and replay HTTP traffic.

A self-hosted MITM proxy and HTTP toolkit for security research. Open source, runs locally, no telemetry.

Open a projectDownload CA cert
Features

Everything runs in your browser. No cloud, no accounts.

Proxy logs

Full HTTP/HTTPS traffic log with search and filter. Inspect headers and bodies for every request your browser makes.

Open logs →

Intercept

Pause requests and responses mid-flight, edit them in the browser, then forward or drop. Essential for manual testing.

Open intercept →

Sender

Craft and replay arbitrary HTTP requests. Import from proxy logs, tweak headers and bodies, send, repeat.

Open sender →

Scope

Regex-based scope rules to filter which hosts and paths are logged or intercepted. Keep your session focused.

Configure scope →
Getting started

01

Create a project

All proxy data is scoped to a project. Create one to start capturing traffic.

Go to projects

02

Install the CA certificate

Download and trust the Lynx root CA so HTTPS traffic is visible in plain text.

Download cert

03

Set your browser proxy

Point your browser's HTTP/HTTPS proxy to 127.0.0.1:8080 and start browsing.
